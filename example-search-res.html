Java Spring Framework

Spring Framework là một nền tảng mã nguồn mở phổ biến cho việc phát triển ứng dụng Java quy mô doanh nghiệp. Với dự án con Spring Boot, hệ sinh thái cung cấp giải pháp đóng gói ứng dụng độc lập (standalone) và giảm thiểu các cấu hình boilerplate thông qua cơ chế tự động cấu hình (Auto-configuration).
